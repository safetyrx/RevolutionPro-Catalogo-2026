REVOLUTION PRO — CATÁLOGO ACTUALIZABLE V21

Esta versión agrega actualización del catálogo desde la propia aplicación.

1. Ejecuta la aplicación.
2. En la barra superior entra en “Actualizar catálogo”.
3. Pulsa “Importar nuevo PDF”.
4. Selecciona el PDF del nuevo catálogo.
5. Espera a que se procesen todas las páginas.
6. Revisa la asignación página → producto.
7. Usa “＋ Agregar producto” si existe un producto nuevo.
8. Pulsa “Guardar configuración”.

El catálogo puede tener más o menos páginas que el anterior. Las páginas nuevas quedan sin asignar hasta que las configures.

La configuración comercial de productos existentes (precios, ofertas y posiciones) se conserva por nombre del producto.

El PDF importado y su configuración se guardan localmente en IndexedDB del equipo. No se necesita servidor ni base de datos externa.

GitHub Actions: ejecutar manualmente el workflow “Build Revolution Pro Catalogo 2026 V21”.
Genera Windows x64 y macOS Universal (.dmg + .zip).
